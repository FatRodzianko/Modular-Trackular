Modular-Trackular

Firmware mods for the Polyend Tracker+, firmware 1.2.0

Add mods to your own copy of the stock Tracker+ firmware, right here in your browser. Your file is read, patched and saved on this device: nothing is uploaded, and this site doesn't host any Polyend firmware.

Use at your own risk. These are unofficial mods, not affiliated with or supported by Polyend. Each mod was tested on one Tracker+, and going back to stock always worked there, but that's no guarantee for your unit. Back up your whole SD card first, and read how to go back to stock before installing.

1 Your stock firmware

Download Tracker+ firmware 1.2.0 from Polyend's website (the Tracker+ firmware downloads) and choose the file here. It's called TrackerPlus_1.2.0.ptf.

2 Choose mods

3 Patch and download

Choose your stock firmware and at least one mod.

4 Install on your Tracker+

    
    
      
  1. Back up your SD card: the whole card, including the Workspace folder.
    2. 
      
  2. Copy the downloaded file into the card's /Firmware folder, next to the stock
        TrackerPlus_1.2.0.ptf. Keep the stock file there. Remove other old .ptf
        versions, so an emergency reflash can only pick one of these two. Keep the file name: Config only
        lists files whose names start with TrackerPlus and end with .ptf.
    3. 
      
  3. On the Tracker+: Config → Firmware, choose the new file and confirm. The unit
        updates and restarts.
    4. 
      
  4. Config now shows the new version text, for example 1.2.0-sw1 Build 1504.
    5. 
    

    
Back to stock

    
Config → Firmware → TrackerPlus_1.2.0.ptf → confirm. Config shows
      1.2.0 Build 1504 again. Some mods keep per-project settings in a small file in the project
      folder (colorsong.bin, humanize.bin, interpolate.bin,
      masterfx.bin, swing.bin). Stock firmware ignores them; deleting one resets
      that mod's settings for the project.

    
If it doesn't start

    
    
      
  1. On a computer, remove the patched file from /Firmware, so only the stock
        TrackerPlus_1.2.0.ptf is left.
    2. 
      
  2. Put the card back, power on, and press the pinhole button next to the USB-C port
        with a pin. The bootloader shows “Updating…” and installs the stock file. The bootloader isn't
        touched by these mods.
    3. 
    

    
If the unit only freezes in one place but starts, pull the power, start it, and switch back to stock
      through Config. If even the reflash fails, contact Polyend support.
